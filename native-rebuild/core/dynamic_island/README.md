# Windows 灵动岛

入口是桌面美化页 Dock 后面的独立卡片。默认关闭，源码不依赖 Dock。交互参考 WinIsland，使用本项目 C++/CMake 自行实现，不引入其 Rust 工程或代码。

## 代码

- `core/dynamic_island/island_model.*`：有界媒体快照与单调时钟专注计时，无 Windows、音乐会话或 WebView 依赖。
- `platform/windows/dynamic_island/island_window.*`：独立 layered HWND、WidgetCanvas/DirectWrite、弹簧动画、分页内容、输入与材质。
- `platform/windows/dynamic_island/system_media_session.*`：Windows 系统媒体会话（QQ 音乐等）的后台读取。
- `apps/shell/dynamic_island_session.*`：UI 线程生命周期与配置。`dynamic-island-preferences.json` 为共享组件偏好，`dynamic-island-preferences-display.json` 保存显示选项；均原子替换，保存失败恢复原运行状态。
- `cmake/DynamicIsland.cmake`：独立 `lume-dynamic-island` 静态库。
- `ui/dynamic-island.*`：设置页、状态校验、中英文文案。

宿主（`apps/shell/desktop_application.cpp` 的 `IslandOptions()`）只传入窄快照和回调：`Media`（会话/歌曲 id、标题、歌手、进度、封面 data URL、频谱）、控制回调，以及 `IslandTodoSource`（按天读取、标记有待办的日期、完成切换、打开日历/待办、编辑、删除）。岛模块不打开媒体文件、不联网、不持有播放主机或待办仓库。

## 行为

- 尺寸（DIP，大小选项 ×0.86/1/1.16）：空闲胶囊 120×30；播放中 236×34（封面、歌名、4 根频谱条，颜色取封面主色）；音乐页展开 372×156；日历/天气/性能/待办页 404×208；提醒 340×62。固定 420×216 画布，只合成可见区域。
- 动画：宽、高、透明度、收起、翻页五个阻尼弹簧，按 DwmFlush 帧时钟与 QPC 计时步进；关闭 Windows 动画效果时直接到位。
- 交互：单击展开/收起；展开后点击其他位置收起（仅展开期间安装 WH_MOUSE_LL，收起或让位即卸载）；滚轮按 音乐（有播放时）/日历/天气/性能/待办/提醒（有待办提醒时） 循环。右键菜单含材质、展开/收起、设置、恢复默认、关闭；待办页另有新建/编辑/删除待办。
- 日历页：“舒展”布局，蓝色强调色，节日蓝点、有待办绿点，点某天进入该天待办。待办页：与日历、今日待办组件共用同一 `TodoSession`，最多 5 行；完成态绿色，编辑器颜色按日历同款整行着色 + 左侧色条表示重要程度。编辑复用 `CalendarTodoEditor`。
- 性能页（1.0.8）：直接复用性能组件的 `DrawPerformance`（CPU、GPU、内存、网络上下行，新增整体透明度参数供翻页淡入），与桌面性能卡片是否开启无关。岛内自带一个 `PerformanceMonitor`，仅在展开且停在性能页时每秒采样一次，离开该页、收起或关闭即停止并等待采样线程退出；刚进入页面的第一秒 CPU 显示“--”（需两次采样求差）。点击无操作。
- 天气页（1.0.7）：404×208 DIP；顶部城市，中部大温度、天气与高低温、右侧天气图形，下方六小时预报。天气图形以原生画布绘制晴/云/雨/雪/雷/雾，未知天气显示问号。数据为天气组件的同一份快照（`dynamic_island::Weather`，最多 6 个小时项），温度舍入、地名简繁与小时标签和天气组件一致。宿主通过 `weatherActive` 回调为岛申请共享数据：桌面天气卡片关闭时仍有天气，卡片与岛同时开启也只运行一个天气 worker，最后一个消费者关闭即停止；不会修改卡片开启偏好。岛内不联网、不定位、不落盘。加载/失败只显示简洁状态；正常天气页点击不弹设置，缺数据时可点击打开天气设置。
- 提醒：灵动岛开启且可显示时，待办提醒经 `LocalReminderPorts::deliver` 在岛内显示 9 秒（悬停保持，点击打开该待办）；关闭或全屏让位时仍走原提醒弹窗与免打扰规则。
- 材质：纯黑（完全不透明）、液态玻璃、磨砂玻璃；玻璃与日历组件一致（opticalProfile 1，近透明填充保持可点击）。
- 不打扰：默认在窗口上方（WS_EX_TOPMOST、不激活）。D3D 独占全屏、演示模式或前台窗口覆盖主显示器时立即隐藏，不播动画（不用 QUNS_BUSY，它也报告其他显示器的全屏）。主显示器上有其他程序的最大化窗口在前台时，收到屏幕顶端只露 6 DIP，避免挡住浏览器标签与标题栏；指针移到边上即滑出，新提醒也会滑出。前台切换由进程外 WinEvent 即时触发，最大化/还原由 1 秒复查发现。
- 自动隐藏（默认开，1.0.6 起；已有配置文件保持原值）：闲置 3 秒后同样收到顶端；切歌或播放状态变化时短暂露出。
- 设置：大小、全屏和游戏时隐藏（默认开）、显示在窗口上方（默认开，关闭回到桌面层级）、悬停自动展开、无活动时自动隐藏、材质、恢复默认。

## 资源

- 启用时有 1 秒复查定时器；动画期间按显示帧步进，结束即停。
- 频谱条 80ms 重绘仅在条形实际可见时运行：播放中、未收起、未显示提醒，且在紧凑态或音乐页；正在动画时不重复重绘。
- 日历页的待办日期集合在宿主缓存，只在待办仓库变化后重建，绘制月历不复制仓库。
- 系统媒体在独立 MTA 线程每秒读取并缓存，UI 线程只取快照；封面分块读取并在缺失时重试，每首歌一次；岛未请求快照 3 秒后停止查询。Lume 音乐封面由 `MusicCoverResolver` 在后台转为 data URL。
- 关闭释放 HWND、钩子、定时器、位图、画布和玻璃。

## 验证

`lume-dynamic-island-test` 在隔离桌面覆盖原生输入、三页滚轮、待办切换、提醒点击、外部点击收起、自动隐藏收起、材质与显示选项持久化、保存失败回滚、损坏配置保护和生命周期，实际绘制帧输出到构建目录 `verification/dynamic-island/`。`lume-desktop-dynamic-island-test` 用真实管理页测试控件协议与关闭/重开。两者纳入标准打包探针。最大化窗口收起依赖真实前台窗口，隔离测试未覆盖，没有宣称 Win10/Win11、全 DPI、多显示器与游戏矩阵已验收。
