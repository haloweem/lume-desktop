# Chinese almanac style artwork

The two `assets/island-styles/calendar-chinese-almanac*.png` thumbnails are generated by
`tests/unit/island_almanac_test.cpp` using the same `DrawIslandAlmanacCard` native
DirectWrite drawing function used by the live island. No source screenshot pixels,
remote images, AI-generated bitmap, embedded web page, or new font file are used.

- Native drawing: `platform/windows/dynamic_island/island_almanac_card.h`.
- Cream paper background and green print, with native binding and fold details.
- Print faces: the system's SimSun / Georgia with DirectWrite font fallback.
- Sample date: 2026-10-16, matching the user's visual reference.
- The thumbnail's 06:24 / 18:01 are illustrative reference times. The live card
  uses the existing weather provider readings for today; absent readings and
  other dates display `--:--`.
- Lunar dates, cycles and activities use the existing offline lunar-javascript
  1.7.7 data. Direction rows come from the pinned upstream v1.7.7 source,
  including the default Fu convention (sect 2). The source, generator, methods
  and hashes are recorded in `core/almanac/almanac_directions.sources.json`.
- lunar-javascript: MIT, Copyright (c) 2018 6tail. Existing license:
  `licenses/lunar-javascript-LICENSE.txt`.

Generated at 2x native card resolution (416 x 416), with transparent round corners.
